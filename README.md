# Praktisk verktygsuppgift

## GitBash
I GitBash skrev jag till exempel *mkdir* "mappnamn" och *cd* "mappnamn" för att skapa en ny mapp och byta till just den mappen.

Det är **väldigt viktigt** att vara noggrann annars blir det fel. 

## VS Code
Här använde jag olika markdowns för att kunna enkelt formatera texten med rubriker, **fet**  och *kursiv* text.

### Kommandon jag använde i gitbash
- git add README.md

Lägg till ändringen i filen till nästa commit

- git commit -m "add README"

Sparar dina ändringar och lägger till en kommentar som är valfri

- git status

Kollar status på hur det ligger till med filändringar. 

- git push

Laddar upp aktuell branch/gren till GitHub.
